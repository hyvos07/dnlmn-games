# The empty level

The launcher owns the error page at `apps/launcher/src/pages/404.astro`. Astro builds
it into `404.html`, which assembly copies to the root of `dist/`.

Keep Wrangler's `assets.not_found_handling` set to `404-page`. Cloudflare serves
the nearest `404.html` with HTTP 404 while keeping the originally requested URL,
including unknown paths inside a game folder. Do not add a redirect to `/404`, a
catch-all successful route, or an SPA fallback. Verify this with the assembled
build and `pnpm preview`; the dev server is not the production routing authority.

The standalone page has no navbar or footer. A compact vertical space shooter sits
above a large “404”, smaller “Nothing here”, and a regular home link. It has `noindex`
metadata without a canonical destination. Its assets use Astro's generated URLs
so they load even when the original request is several directories deep.
Its backdrop is the solid body background: the minimal layout omits the launcher's
scene element entirely. Keep plain-error styling separate from the landing page's
gradient, dotted poster, and floating WebGL pieces; don't override shared scene CSS.

“Void Patrol” is a launcher-local space shooter, not a published game. Its code-drawn
Canvas 2D arena is 9:10 and at most 360px wide. It auto-starts and auto-fires: steer
in both axes with mouse movement or touch/drag. The ship replaces the mouse cursor
inside the arena and follows it directly, clamped within its edges and below the HUD.
All arrow keys and WASD move the ship while the canvas is focused. Lasers originate
from the ship's current position; enemy-shot and body collisions use that position.
Destroy enemies for 100 points each; clear formations to advance waves.
Three shields absorb hits. Enemy shots and breached formations cost shields;
brief invulnerability prevents a group of overlapping hits from ending a run at once.
A compact Fly again button and “Nice try.” appear after losing all shields. There is no audio or saved
data; score resets on refresh, a new visit, and a back/forward-cache return. Keep it inside
the launcher; do not import code from `games/` or introduce a game manifest/SDK
HUD just for this error-page interaction.

The error message and navigation work without JavaScript. Gameplay loads and starts
automatically after the static page paints. Stars, thruster flicker, impact sparks,
and anime.js score pulses respect `prefers-reduced-motion`; essential enemy/laser
movement remains playable. Simulation pauses while the tab is hidden or the arena
is offscreen. Keyboard handlers belong to the canvas, not the window, so normal
navigation remains available. The no-JavaScript fallback has an original SVG space poster.
Rules/collision/scoring are separate from rendering and input, use fixed simulation
steps, and keep entity/effect counts bounded. No new runtime dependency is needed.

All ship/enemy artwork and game code here are original; no example artwork/code is copied.
