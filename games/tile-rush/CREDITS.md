# Credits

All visual assets and sound effects are original to this game: SVG pixel creatures, a drawn SVG favicon, interface styling and Web Audio synth effects. Completed pixel tiles reuse the same original SVG with dimming. Game text uses system fonts; shared SDK headings use the self-hosted font below.

- **Bricolage Grotesque**, distributed through [Fontsource](https://fontsource.org/fonts/bricolage-grotesque), licensed under the [SIL Open Font License 1.1](https://github.com/ateliertriay/bricolage/blob/main/OFL.txt). Used for the SDK pause and help headings, matching the other games. Font files ship with the game; no third-party font service is contacted.

Gameplay inspiration: [EatOwi by hyvos07](https://github.com/hyvos07/EatOwi), itself based on [EatKano by arcxingye](https://github.com/arcxingye/EatKano). This implementation was written for this repository; no upstream code, photos, sounds or other assets are redistributed.
